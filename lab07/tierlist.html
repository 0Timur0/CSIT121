Reflection

While creating this tier list, I had to learn more about HTML tables and how the structure works and how to use the different tags. I also learned how to use CSS and classes to style the table and make each tier feel and look unique. I also added images to make each row more visually appealing and larger. And I had to use the scope attribute to make the table more accessible for screen readers. Overall, I had a lot of fun creating this tier list.
